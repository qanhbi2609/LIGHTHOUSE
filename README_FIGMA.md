# LIGHTHOUSE — bản chỉnh giao diện theo Figma (chưa phải Final)

**Nguồn thiết kế:** https://www.figma.com/design/xF9VqYXD2TgESMQZpN7e5a/Untitled?node-id=461-3048

## Chạy thử ở Windows
1. Giải nén ZIP.
2. Mở `run-demo.bat` (cần Node.js ≥20).
3. Vào http://localhost:3000.
4. Tài khoản dữ liệu mẫu: `quanly@lighthouse.test`, mật khẩu `Demo@123`. Chỉ dùng dữ liệu giả.
5. Dùng lệnh `cd backend && npm test` để chạy kiểm thử API.

## Tình trạng
- Cấu trúc giao diện chính và một số screen đã chỉnh theo Figma.
- Chưa đối chiếu visual từng Frame; chưa đủ điều kiện xem là giao diện hoàn toàn trùng thiết kế.
- Backend có demo các nhóm UC nhưng JSON không thay thế SQL Server thật.
- **Chưa deploy online**. Không đụng tới GitHub nhóm và không tạo dịch vụ Render trong workspace dùng chung.

Đọc `FIGMA_AUDIT.md` để xem danh sách vấn đề và tiêu chí nghiệm thu còn thiếu.
